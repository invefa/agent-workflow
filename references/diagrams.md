# 绘图工具参考

按需阅读。本篇保存drawio命令行工具链的历史做法，具体版本和平台能力先核对当前帮助；图形工具与交付格式根据任务选择。视觉原则见[书写与组织](../writing.md#四视觉表达)，不要求所有图都使用本工具。

## 一、源文件与导出

需要可编辑drawio交付物时，图源和生成脚本放在figures-src，figures只存正文引用的SVG；目标不支持SVG时再生成构建目录中的位图兜底。下面是原桌面工具的导出形状，路径和参数按当前环境替换：

```powershell
$diagramTool = '<drawio executable>'
& $diagramTool -x -f png -e -s 3 -b 14 --theme light -o './build/diagram.png' './figures-src/diagram.drawio'
& $diagramTool -x -f svg -e -b 14 --theme light -o './figures/diagram.svg' './figures-src/diagram.drawio'
```

| 参数 | 历史用途 |
|---|---|
| -x、-f | 导出及目标格式 |
| -e | 嵌入可编辑图源，方便重新打开 |
| -s | 位图倍率 |
| -b | 导出边距 |
| --theme | 指定导出主题，须与交付物一致 |

生成mxGraphModel XML时先做XML合法性检查，标签中的HTML先转义再写入属性。外部导出设置超时，并检查退出码、文件非空与实际显示；遇到失败可查[XML故障经验](troubleshooting.md#一xml属性与导出挂起)。

## 二、尺寸与阅读

按最终阅读容器选择画布、字号和导出倍率。原报告约600px画布、3倍位图导出时较清楚，这是特定字体与缩放环境的经验；宽流程图、横向页面或不同显示密度需要重新检查。

默认用位置、边框和少量颜色表达层级；不强制固定圆角、主题或无填充。检查重叠、连线、文字裁切与缩放后的字号。程序生成的图可先做边界与布局校验，再在最终阅读尺寸目检。

## 三、历史参数

| 项 | 原模板参考值 |
|---|---|
| 画布宽度 | 约600px |
| 位图倍率 | 3倍，按实际清晰度调整 |
| 外边距 | 14 |
| 标题、正文、注释 | 14、11至12.5、9至10.5 |
| 小圆角 | arcSize=4 |
| 常规、强调线宽 | 1、1.8 |
| Word嵌图宽度 | 原脚本以画布宽度除以100换算为英寸，受页面正文宽度约束 |

这些数值不能单凭屏幕像素推断印刷效果。需要其他格式、深色主题或不同纸张时，使用对应环境的实际渲染结果。

## 四、SVG标签与总线连线

在原drawio导出环境中，顶点标签主要通过foreignObject携带HTML并附位图兜底；部分边标签在html=0时输出text。核查时解析SVG统计text与foreignObject，并在实际阅读宿主中检查。仅搜索到标签文字不能证明文字是纯矢量，也不能仅凭SVG扩展名判断清晰度。纯矢量文字需要当前工具支持的纯文本排版方式，必要时改用单行或图外标签。

SVG可以直接在目标宿主中目检；需要临时PNG辅助时输出到构建目录，不混入正文图片目录。Word嵌入的宿主差异见[Word矢量参考](word.md#23-图片嵌入)。

总线式连线默认不依赖自动正交路由。原实现的端点进出方向不同时，自动路由会额外插入折线，形成并排竖线和小矩形。采用edgeStyle=none，在mxGeometry的Array as="points"中显式给出折点，并按画布坐标检查。此经验针对总线布局，不禁止所有图使用自动路由；更换工具或布局后重新验证结果。

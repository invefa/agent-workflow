# 命令行工具

适用于构建或修改面向终端、脚本和管道的工具。参数语法沿用 Linux 用户熟悉的 POSIX 工具习惯和 GNU 常用约定，同时保护已有工具的兼容承诺。

## 一、命令与选项

- 命令和子命令按职责命名。同一长选项或短选项在作用范围内保持同一含义。长选项表达完整语义，频繁手工使用的选项可提供短名。支持 `--` 结束选项解析。取值写法和短选项组合的规则沿用解析器与项目惯例，并列在帮助中。
- 提供 `--help` 和 `--version`。帮助按命令显示适用的选项、候选值、默认值和典型用法。帮助与版本查询正常退出，并保持只读。复杂 CLI 尽量让解析、校验、帮助和补全使用同一套选项定义。
- 若支持命令、子命令或枚举的前缀简写，优先匹配完整名称，再接受唯一前缀，歧义时列出候选。脚本、Agent 调用和持久配置使用完整命令、长选项与枚举值。通常对路径、标识符和自由文本保留输入原值。
- 写明配置与显式参数的覆盖顺序。配置启用的选项应有明确的关闭或清除方式，避免已取消的选择被配置重新填回。写入前拒绝未知参数、非法值和冲突的选项。

## 二、输入输出与终端行为

- 可与其他工具组合的命令，应支持适合业务的标准输入与管道。标准输出保留命令结果，诊断和进度用标准错误。成功、用法错误和执行失败使用有文档且稳定的退出行为，脚本可以据此判断下一步。
- 分开数据范围、过滤、排序、内容详略、显示格式和交互阅读。明确输出的数据来自同一查询结果。需要集成时，提供稳定的结构化格式，让脚本获取完整数据。终端表格的列宽、颜色、分页或摘要不改变业务数据和机器输出。
- 根据输入输出是否连接终端决定交互行为。重定向和机器输出默认不等待按键，不混入终端颜色、进度控制字符或分页提示。人读输出按实际显示宽度布局，窄屏时可折行或选择详情显示。

验证时同时检查交互终端、管道或重定向、关键信息的结构化输出以及错误退出。遇到语法取舍时可查 [GNU 命令行约定](https://www.gnu.org/prep/standards/standards.html#Command_002dLine-Interfaces)和 [GNU Coreutils 通用选项](https://www.gnu.org/s/coreutils/manual/html_node/Common-options.html)。
